Option B: Manual Capture

Manual Steps:

  1. Open Developer Tools (F12) in the Nest window
  2. Go to the Network tab
  3. Enable "Preserve log"
  4. Refresh the page (F5)
  5. In the filter field: Type issueToken
  6. Click on the request (starts with iframerpc)
  7. Copy the full Request URL
  8. In the filter field: Type oauth2/iframe
  9. Click on the last request
  10. Under Headers → Request Headers: Copy the entire cookie: value
