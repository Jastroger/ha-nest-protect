🔧 Nest Protect Credential Helper

Dieser Helper vereinfacht die Erfassung der benötigten Credentials erheblich.

Schritt 1: Bei Nest anmelden

Öffnen Sie home.nest.com und melden Sie sich an:

⚠️ Wichtig: Verwenden Sie ein Inkognito/Privates Fenster und aktivieren Sie Third-Party-Cookies.

Schritt 2: Credentials erfassen

Nachdem Sie angemeldet sind, haben Sie zwei Möglichkeiten:

Option A: Automatische Erfassung (Empfohlen)

Öffnen Sie die Browser-Console im Nest-Fenster (F12 → Console) und fügen Sie diesen Code ein:

Option B: Manuelle Erfassung

Manuelle Schritte:

  1. Öffnen Sie Developer Tools (F12) im Nest-Fenster
  2. Gehen Sie zum Network Tab
  3. Aktivieren Sie "Preserve log"
  4. Aktualisieren Sie die Seite (F5)
  5. Im Filter-Feld: Geben Sie issueToken ein
  6. Klicken Sie auf den Request (beginnt mit iframerpc)
  7. Kopieren Sie die vollständige Request URL
  8. Im Filter-Feld: Geben Sie oauth2/iframe ein
  9. Klicken Sie auf den letzten Request
  10. Unter Headers → Request Headers: Kopieren Sie den gesamten cookie: Wert
